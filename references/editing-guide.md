# 精准编辑与视觉换皮指南

## 核心原则

编辑任务的核心是"最小差异"：修改越少，提示词越短，结果越可控。先声明严格保留原视频未点名的内容，再逐项写明最终变化。不要重新创作无关镜头。

## 变更清单

编辑开始前，建立内部变更清单，每项包含：
- 对象：被修改的人/物/场景/声音
- 位置：在时间轴上的哪一段
- 原状态约束：保留什么物理关系（遮挡、光影、运动模糊）
- 最终状态：修改后的精确描述

四类标记：
- 保留：严格不变的内容
- 修改：改变属性的对象
- 删除：移除的元素
- 新增：原本不存在的元素

## 精准编辑写法

将编辑写成最小差异指令：

```
严格复现视频1的时长、镜头、动作、构图、节奏和声音，只做以下变化：
- 将人物右手的黑伞替换为白色郁金香，花茎朝上，郁金香高度与原伞柄等长
- 人物握持方式改为花茎中部握持，手指自然弯曲
- 郁金香在风中轻微摆动，与原伞的晃动节奏一致
- 其余内容保持不变
```

要点：
- 逐条列出最终状态，不写"原来是什么、现在改成什么"的解释
- 多项修改有关联时补充同步关系（如换背景后同步人物光线与地面阴影）
- 换入对象必须适配原有握持、接触、运动模糊、反射和阴影

## 视觉换皮

把结构与视觉分开控制：

锁定不变（不改）：
- 时间轴
- 动作功能（走、跑、转身、拿起）
- 机位
- 运镜
- 转场
- 卡点

重做（替换）：
- 人物
- 服装
- 产品
- 环境
- 道具
- 色彩
- 品牌视觉

最终 prompt 直接写新的成片内容，不写"原来是什么、现在改成什么"。

## 人物与产品一致性

### 人物锁定

按需写明：同一身份、年龄、五官比例、发型发色、体型、服装版型、配饰数量。
允许变化的通常只有：表情、视线、姿势、呼吸、自然的头发或衣料运动。

在 subject_definitions 中锁定，素材中用 <Subject N> 引用，不重复描述。

### 产品锁定

按需写明：整体轮廓、长宽比例、部件数量、开合方式、标签文字、Logo 位置、颜色、材质、反光方式。
涉及拆解或变形展示时，要求部件对齐、数量守恒并最终准确复位。

## 文字、品牌与 UI 控制

### 文字白名单

列出唯一允许出现的文字，要求：
- 拼写准确
- 大小写准确
- 数值准确
- 出现次数明确

```
文字白名单：仅允许出现 "MINIMAX" 品牌字样，出现在画面右下角，白色无衬线字体，字号占画面高度 3%，停留 3 秒后淡出。不得出现其他文字。
```

### 文字位置与动效

- 位置：画面坐标（居中/右下/顶部居中）
- 层级：前景/背景/叠加层
- 入场方式：淡入/滑入/弹出
- 退场方式：淡出/滑出/消失
- 停留时间：精确到秒

### UI 屏幕锁定

UI 元素需要屏幕锁定时明确说明，不随相机透视漂移：
```
UI 元素固定在屏幕坐标位置，不随镜头运动产生透视变化。血条位于画面顶部居中，技能图标位于画面右下角 2x2 排列。
```

文字可读性比装饰效果优先。

## 声音编辑

写清原声中哪些层保留、替换或删除：
- 更换台词时同步修改口型、停顿、呼吸、表情和动作强度
- 更换音色时保持说话人身份和空间声学合理
- 禁止新增用户未要求的旁白或配乐

声音参考与画面参考分开绑定，不要用一段模糊的"电影级音效"覆盖全部需求。

## 高精度指令遵循

多项修改拆成原子清单，每项检查：
1. 是否遗漏任何一项修改
2. 是否意外改变未点名内容
3. 多项修改之间是否互相冲突
4. 变化是否同步影响光影、遮挡、声音和物理接触
5. 文字、颜色、数量、左右位置和先后顺序是否准确

单点修改使用短指令（1—4 句）；多点修改使用清晰列表。不要把精准编辑扩写成一次新的故事创作。
