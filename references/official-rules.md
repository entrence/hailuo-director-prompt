# MiniMax H3 (海螺导演台) 官方能力边界

更新时间：2026-08-01。以下内容作为生成和校验的硬约束；如果 GK 要求核对最新版，重新查看官方文档后再更新本文件。

## 支持的工作方式

- 文生视频：只提供文字提示词，不提供参考素材。
- 首帧/尾帧图生视频：提供文字和 0—2 张首尾帧图片；不提供图片时等同文生视频。
- 多模态参考生成：使用图片、视频、音频的任意有效组合，控制人物、产品、动作、镜头、风格、声音或剪辑节奏。海螺导演台的主入口。
- 视频编辑：通过参考视频与精准文字指令，修改人物、物体、场景、光影、声音和节奏；属于多模态参考生成的应用方式。

## 输出限制

| 项目 | 限制 |
|------|------|
| 模型名 | MiniMax-H3 |
| 分辨率 | 2K |
| 时长 | 4—15 秒，只接受整数 |
| 画幅 | 支持常见画幅或自适应；文生视频必须明确画幅且不能使用 adaptive |
| Prompt | 不超过 7000 字符 |

## 输入限制

### 首尾帧入口

- 图片数量：0、1 或 2 张。
- 图片宽高：256—5760 像素。
- 宽高比：2:5—5:2。
- 支持 JPG、JPEG、PNG、WEBP、HEIC、HEIF。

### 多模态参考入口

- 图片：最多 9 张，每张不超过 30 MB。
- 视频：最多 3 段，每段 2—15 秒，合计不超过 15 秒，每段不超过 50 MB。
- 音频：最多 3 段，每段 2—15 秒，合计不超过 15 秒，每段不超过 15 MB。
- 混合输入：所有图片、视频和音频合计不超过 12 个文件。
- 音频不能单独作为参考输入，必须同时提供至少一张图片或一段视频。
- 视频支持 H.264/AVC、H.265/HEVC；视频内音频支持 AAC、MP3。
- 音频支持 WAV、MP3。
- 单次 API 请求体不超过 64 MB；大文件优先使用 URL。
- 图片和视频宽高范围均为 256—5760 像素，宽高比为 2:5—5:2。

## 素材职责说明

- 图片可负责人物、产品、场景、风格、首帧或尾帧。
- 视频可负责动作、机位、运镜、剪辑节奏、表演和需要保留的原始内容。
- 音频可负责声音、音色、对白、音乐节拍和音效节奏。
- 多个参考素材必须在提示词中明确各自职责，避免身份、动作或风格互相污染。

## 配额关系

海螺导演台 UI 中，公共参数和所有素材共用全局总池：
- 9 图 / 3 音 / 3 视频是全局共享配额，不是每段素材独立。
- 素材提示词框内挂载的参考素材也计入这个池子。
- 图片+视频+音频合计不超过 12 个文件。
